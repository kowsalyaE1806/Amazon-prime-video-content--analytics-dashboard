# Amazon-prime-video-content--analytics-dashboard

# Project Overview
An interactive Power BI dashboard developed to analyze Amazon Prime Video's content library and identify trends across genres, ratings, countries, content types, and release years.

# Tools & Technologies
Power BI
Power Query
DAX
Data Visualization

# Dashboard Features

📊 Ratings by shows
🎬 Movies vs TV Shows
🎭 Genre-wise content analysis
🌎 Country-wise distribution
📅 Release-year trends
📈 Total titles overview

## Key Insights

- Movies make up the majority of the content library.
- Drama is one of the most prominent genres.
- The dashboard highlights content distribution across countries.
- Content additions increased significantly in recent years.
- Ratings provide an overview of the target audience for different shows.
